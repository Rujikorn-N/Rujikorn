# AI-assisted Nanopore Protein Classification

This repository contains code and analysis for a senior research project on machine-learning analysis of nanopore current blockade signals for single-molecule protein identification.

## Project overview

The project investigates whether nanopore current blockade signals can be used to distinguish protein targets, with a focus on Human Serum Albumin (HSA) and Fragment Factor VIII (F8).

The work includes signal/data preprocessing, exploratory data analysis, feature-based machine-learning classification, model evaluation, and experiments involving protein mixtures. The project is also being expanded toward analysis of raw nanopore signals and additional feature engineering.

## Current contents

- `notebooks/ml_1.ipynb` — current analysis / machine-learning notebook.

## Data

Raw experimental datasets are not included in this public repository at this stage. This is intentional because the datasets may be subject to research-data sharing restrictions and can also be large.

## Methods

The project uses Python and common scientific machine-learning tools, including pandas, NumPy, Matplotlib, and scikit-learn.

## Research context

This work is related to nanopore sensing and machine-learning-based protein identification. The project builds on concepts and methods from prior nanopore protein-identification research.
